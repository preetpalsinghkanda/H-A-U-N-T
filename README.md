# H A U N T

A interactive horror themed movie website made with React js, GSAP, and more.
A different kind of horror movie website made for PC or Desktop
You can search for any horror movie you like and explore more about it using the TMDB api

The website has creepy sound, animations, scary videos, and many small details to make the experience more fun and mysterious
Everything is made to be interactive with gsap

Explore HAUNT and find a movie for tonight

> This website contains horror images

## Demo url

`https://h-a-u-n-t-xu3f.vercel.app/`


## Teck Stack

- React js
- GSAP
- Tailwind CSS
- React Router DOM
- Lenis
- Howler
- JS
- HTML and CSS

## Features

- Search any Horror movie
- Smooth Scroll (lenis)
- Scroll Trigger animation
- Interactive hover and scroll effects
- Movie posters and details using TMDB api
- Made for Desktop/PC
